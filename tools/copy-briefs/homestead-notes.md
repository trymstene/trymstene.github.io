# The Homestead — the sign before the story

A new banana lands on the homestead with a tent, a mailbox and a sign. The sign gets a name only
at the story's move-in (Chapter 1's last stretch, when Nib the clerk has handed over the plot),
never before — Trym, 18 Sep 2026: a name asked in the first minute is too early.

One field:

- `signEarly` — the toast when a new banana taps the sign before that: the sign is not theirs
  to write yet, and the letter in the mailbox is where it starts. Warm, plain, one sentence,
  the questline's voice bar (a 13-year-old and a 50-year-old read it without a stumble). No
  "registry", no "deed": the big book, the letter, the clerk.
